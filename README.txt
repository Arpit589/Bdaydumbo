BIRTHDAY SURPRISE — DUSK EDITION V2
====================================

A plain HTML/CSS/JavaScript birthday-surprise website. No libraries, npm, build tools,
frameworks, or external font dependencies are required.

SETUP
-----
1. Keep this folder structure:
   birthday-surprise/
   ├── index.html
   ├── style.css
   ├── script.js
   ├── images/
   │   ├── birthday-person.jpg
   │   ├── angry-pet.gif
   │   ├── us-1.jpg
   │   ├── us-2.jpg
   │   ├── us-3.jpg
   │   ├── us-4.jpg
   │   └── us-5.jpg
   └── music/
       └── song.mp3

2. Open index.html directly in a browser, or use VS Code Live Server.

EDITING
-------
Open index.html and search for "REPLACE WITH".

You can edit:
- birthday person's name
- the three appreciation messages
- vintage letter date
- vintage letter greeting
- vintage letter body
- optional second letter paragraph
- letter sign-off and name

The vintage letter content is deliberately kept in index.html rather than JavaScript,
so it is easy to find and replace in VS Code.

MEMORY GALLERY
--------------
The gallery contains exactly five memory photos:
us-1.jpg through us-5.jpg.

The project has no dependency on a sixth memory photo.

NOTES
-----
The existing slide navigation, music control, cake/candle interaction, confetti,
typewriter finale, responsive layout, and dusk palette have been preserved.
